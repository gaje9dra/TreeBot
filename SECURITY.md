# Security Policy

TreeBot is experimental trading software. Do not connect a wallet holding funds you cannot afford to lose.

## Reporting a vulnerability

Do not publish exploit details, credentials, private keys, recovery phrases, or sensitive transaction data in public issues. Contact the repository owner through a private channel and include affected commit, impact, reproduction steps, and suggested mitigation.

## Release posture

Paper mode only. Deposits and live swaps are not implemented and must remain disabled. Any future smart contract handling user funds requires independent audit/review before mainnet use. No audit is claimed for this repository.
